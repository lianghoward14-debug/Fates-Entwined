# Replacement AI decision code

The decision system is in `shared/ai/`. Browser layout/startup repair is being handled separately; this document does not certify that integration.

## Entry points

- `chooseCommand(commands, projection, context)` returns an exact supplied legal template. Supply `context.canonicalState`, `playerIndex`, `difficulty`, and `style` for full search. Without canonical state it uses a visible-information ordering fallback.
- `planDecision` exposes the selected move, sampled principal variation and diagnostic trace. The continuation is hypothetical; callers must replan after each accepted command.
- `src/scripts/authoritative-v3-ai-policy.mjs` retains the existing import/export names as a compatibility interface to this policy.
- `new-ai-worker.mjs` and `new-ai-worker-client.mjs` provide browser worker transport. The search code does not own UI or match mutation.

## Implemented

- Real legal commands and reducer outcomes, actor-aware reactions and opponent continuations.
- Bounded search with reserved continuation budgets, source and zone diversity, explicit turn handoff, and terminal-outcome priority.
- Multiple hypothetical worlds, shuffled future draw order, sampled hidden hands, composition limits and affinity priors. Actual opposing hidden identities and live RNG do not seed these samples.
- Risk-sensitive aggregation across worlds and conservative principal-variation diagnostics.
- All 38 named/generated personality styles affect resources, development, pressure, preservation, zone control, disruption and risk tolerance.
- Real Morale calculation forecasts and engine zone scores.
- Reinforcement availability, discounted access to expensive hand cards, setup delay, stranded-card penalties, remaining reaction uses, and Havano placement-cap accounting.
- Replanning after every resolution; old cached action sequences are discarded.
- Deck supply/demand audit and board dependency analysis remain available independently of move selection.

## Limits

Search is bounded and approximate, not exhaustive. Hand-access estimates do not prove that a consolidation is legal. Hidden-card priors are not trained opponent deck inference. Existing opponent-owned private reaction options are excluded from sampled roots; subsequent reactions are generated by the reducer from sampled hands. A principal variation is not a guaranteed sequence against a human opponent.

Earlier validation included tactical fixtures, 38-personality safeguards, browser worker execution, and two completed full starter-deck games won against a basic priority baseline. The final decision-code changes were not run through that suite at the user's request. These results do not establish expert-level strength.

## Continuation planning update

`shared/ai/continuation.mjs` now spends small remaining branch budgets on a real-command continuation through the current turn and an opponent turn. Search invokes it instead of repeatedly subdividing the budget into unfinished branches. It considers distinct sources/targets, explicit END_TURN and reaction decline, and reports completed versus incomplete continuations. This is a greedy bounded rollout beneath the adversarial search, not exhaustive full-turn minimax; incomplete continuations remain possible and are disclosed in diagnostics.

Voluntary manual discard no longer receives the discarded card's printed-effect priority. Its ordering accounts for lost board contributions. All changes in this update are confined to shared AI modules and this document; no gameplay, layout, startup or repair files were changed. Syntax checks passed; no additional game tests were run.

## Reaction continuation fixes

Continuation comparisons now reserve equal bounded budgets to resolve nested prompts before scoring candidate effects. Follow-up destinations, targets and opponent reactions use their actual controlling player, and the selected answers remain in the principal variation. Reaction search preserves distinct sources and NEGATE/SUPPRESS modes through its post-evaluation pruning. Target sets and destination zones remain distinct in continuation ordering.

Continuations inherit the search's remaining depth and already-used turn actions, preventing the rollout handoff from resetting those limits. Budget or depth exhaustion can still leave an effect unresolved; this is not exhaustive reaction solving. Only AI modules and this document were changed in this update. Syntax checks are the validation for this update; playing-strength improvements have not been measured.

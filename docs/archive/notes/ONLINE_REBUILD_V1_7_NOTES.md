# Fates Entwined Online Rebuild V1.7 — UI polish pass

This version is intentionally UI/display-focused only. It does not change RTDB rules or gameplay syncing.

Changes:

- Google account panel now only appears on the title screen.
- Google account panel now displays the stable FATE code, not the chosen username.
- Free Play room-code window art is larger, centered, bordered, and better fitted.
- Social screen layout is rebalanced:
  - shorter/compact left column for Player ID, Add Friend, Friends
  - larger right-side Online Players section
  - pending requests are moved behind a compact Requests button/modal
- Inspected online profiles now use the same design language as the title/Profile tab:
  - larger framed profile picture
  - chosen username
  - FATE code chip
  - rank badge
  - level badge
  - Challenger Elo / record / winrate stats
  - real bio
  - no XP progress bar
- World Chat behavior is unchanged from V1.6.

No new database rules are required if V1.6 rules are already published.

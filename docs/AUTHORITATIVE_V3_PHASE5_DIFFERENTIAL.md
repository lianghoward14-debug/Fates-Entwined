# Authoritative v3 Phase 5 differential testing

The Phase 5 differential runner now consumes the actual
`fates-legacy-action-corpus-v2` recorder envelope. It no longer sends wrapped
legacy snapshots or `LEGACY_*` commands directly to the shared reducer.

For each stable recorded action, the offline adapter:

1. translates the captured legacy state into a complete invariant-valid v3
   state;
2. translates supported `LEGACY_*` action names and coordinate fields into one
   v3 command;
3. executes that command through `reduceCommand`;
4. normalizes the v3 result to the recorder's visible-outcome schema;
5. compares only fields that the recorder measured.

This is offline Phase 5 tooling. It does not run a shadow engine in a live
server or client match and does not begin Phase 6.

The v2 report separates:

- exact matches;
- translation failures;
- unexpected, unclassified mismatches;
- declared mismatches classified as `new-engine-defect`,
  `existing-single-player-defect`, `intentional-rule-clarification`, or
  `cosmetic-only-difference`.

An unexpected or unclassified mismatch fails the command. A declared mismatch
must include a rationale.

`docs/fixtures/AUTHORITY_V3_PHASE5_LEGACY_PARITY_CORPUS.json` is deliberately a
small deterministic recorder-schema compatibility fixture. It gates state,
command, outcome, and classification plumbing across set, end-turn, and
concession boundaries. It is not presented as the required large legacy
self-play parity corpus.

Run the committed fixture with:

```text
npm run replay:authority-v3 -- docs/fixtures/AUTHORITY_V3_PHASE5_LEGACY_PARITY_CORPUS.json
```

Phase 5 promotion still requires real recorder exports from representative
legacy self-play matches, broad card/landscape coverage, and classification of
every normalized mismatch.

## Real legacy baseline

`AUTHORITY_V3_PHASE5_REAL_LEGACY_SELF_PLAY_CORPUS.json` is generated by the
actual legacy browser AI path under the tooling-only combination
`?fateV3Recorder=1&fateV3LegacyCorpus=1`. The driver refuses
`?fateV3SinglePlayer=1`, imports no v3 authority module, and routes both seats
through legacy move generation, evaluation, placement, consolidation, effects,
and turn transitions.

The committed baseline contains 20 matches, 180 stable action boundaries, all
20 starting-landscape scenarios, and 67 played card IDs. Recorded and inferred
nested choices replay serialized v3 prompts. The current gate passes with 178
exact matches, two reviewed `existing-single-player-defect` classifications,
zero translation failures, and zero unclassified mismatches.

The legacy-state adapter reconstructs completed Ali hand transfers, Ali's
six-card hand-limit status, Carpathian Specter counters, self-target choices,
and optional prompt cancellations from the stable pre/post snapshots. The two
remaining non-exact results are explicitly retained:

- Snow Shoveler recovers cards under Zion Canyon in legacy even though that
  landscape forbids discard recovery. Authoritative v3 preserves the
  landscape rule.
- Legacy AI can continue while Ali's mandatory hand-limit resolution is
  deferred, folding that resolution into a later card action. Authoritative v3
  requires the hand-limit command to resolve first.

The capture also exposed and fixed two legacy AI runtime defects where Fort
Calvin and Hemorrhaging Wound referenced an undefined `card` variable instead
of the placed `inst`.

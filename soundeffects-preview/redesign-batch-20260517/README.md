Open audition.html in a browser to listen, or play the WAV files directly.

Suggested review flow:
1. Pick one favorite per event type.
2. Call out any sounds that are too loud, sharp, muddy, or long.
3. Then wire only selected files into src/scripts/08-audio-and-meta-ui.js or keep using procedural synth for events that already feel good.
